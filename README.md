# Team 5 — Predictive Modeling (Stage 3)

## Purpose
Train an Artificial Neural Network (ANN) to predict the `Churn` label using the prepared telecommunications dataset.

## Architecture
- **Input:** all usable predictor columns, excluding the churn target and common customer ID columns.
- **Preprocessing:** median imputation and standardisation for numeric features; most-frequent imputation and one-hot encoding for categorical features.
- **Hidden layers:** 64 neurons, then 32 neurons.
- **Activation:** ReLU.
- **Output:** churn probability; default classification threshold 0.50.
- **Loss:** binary cross-entropy/log loss.
- **Optimiser:** Adam.
- **Overfitting control:** early stopping.
- **Evaluation:** held-out stratified 80/20 split; accuracy, precision, recall, F1, ROC-AUC, confusion matrix, ROC curve and loss curve.

## Run
From repository root:
```bash
pip install -r Predictive_Modeling/requirements.txt
python Predictive_Modeling/train_ann.py
```
The script looks for `Data_Preparation/telco_preprocessed.csv` or `Data_Preparation/training_set.csv`. If your filenames or folders differ, update `CANDIDATES` in `train_ann.py`.

## Outputs
The script saves the trained pipeline in `models/ann_churn_pipeline.joblib` and metrics, test predictions and plots in `outputs/`.
